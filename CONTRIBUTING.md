# Como contribuir

1. Crie uma branch `feature/nome-da-melhoria` a partir de `develop`.
2. Faça alterações pequenas e escreva testes para novas regras de negócio.
3. Execute `ruff check .` e `pytest -v` localmente.
4. Use mensagens de commit claras, por exemplo `feat: exporta relatorio` ou `test: valida duracao da sessao`.
5. Abra um Pull Request para `develop` e descreva as mudanças e os testes executados.

Mantenha o escopo simples e não inclua arquivos de dados pessoais no repositório.
